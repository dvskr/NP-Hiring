# NP Job Board — Surface Completeness Verdict

Synthesized from 6 read-only audits (filters/taxonomy, category tiers, pSEO coverage, metadata/sitemap, navigation mesh, content/components). Top 5 hole claims independently spot-checked against the repo on 2026-08-11; all confirmed, none dropped.

## Verdict

The surface is **not complete: it has 12 genuine holes**, though the core is in strong shape — all 45 taxonomy slugs have parity across routes, tags, assets, sitemaps, configs, and tests in both directions, and the vast majority of gaps the audits found turned out to be documented, deliberate choices. Of the 12 genuine holes, three matter to real users or search engines today: the sitemap index undercounts city batches so tail-batch URLs are never submitted to Google (verified: `app/api/sitemaps/index/route.ts:16` still imports the 28-slug state-eligible set while `app/api/sitemaps/cities/[batch]/route.ts:23` emits against all 45 city-eligible slugs, and the index's "can never disagree" comment is now false); the location input promises city/'Remote' matching that returns zero results by construction; and deep-linked filters (cityExact/stateCode/employer) silently narrow results with no pill, count, or clear affordance. The remaining nine are small mechanical fixes (missing FAQ, provenance line, bylines, nav links, comment drift) or documentation debt. Nothing found suggests structural rot — the drift-test discipline is holding; the holes are seams where a surface was widened and one consumer wasn't updated.

## PASS Summary

- **Search filters vs taxonomy** — All 45 registry slugs covered by tagger rules and filter matchers with `withTagFallback` (no slug silently ignorable); 17-specialty facet is registry-derived so dead slugs are impossible; parse/serialize round-trips all 15 fields; recruitmentType shipped end-to-end schema→admin→clause→facet→pill→probe. Strongest cross-check: `CANONICAL_CATEGORY_SLUGS` set-equality to `ALL_CATEGORY_SLUGS` enforced by test.
- **Category tiers parity** — 45/45 landing+city routes, 28/28 [state] routes, 45/45 asset-registry and tagger entries, both directions zero-diff; P1 #15 verticals at full tier parity. Strongest cross-check: `tests/seo/jobs-segments-drift.test.ts` (9/9) run live and green.
- **pSEO coverage** — Render gate (3 jobs) = sitemap gate on every tier; 36h staleness shared between sitemap and cron probe; cursor+chain covers all 4,135 cities per scheduled run (chain depth 25 vs 21 needed); 51-state salary/licensure/SOP surfaces all derive from one 51-key practice-authority dataset so they cannot disagree. Strongest cross-check: `aggregate-pseo-cursor.test.ts` 31/31 + shared-gate imports in `app/sitemap.ts:25-34`.
- **Metadata/sitemap/404s** — Zero indexable pages missing title/description/canonical; OG on all representatives with robots carve-out for `/api/og`; auth surfaces triple-guarded (per-page robots, middleware X-Robots-Tag, robots.ts re-block past date); sitemap sections gate on the same conditions their pages notFound() on. Strongest cross-check: sitemap imports the pages' literal gate functions (`app/sitemap.ts:30-34`).
- **Navigation mesh** — Header/Footer/homepage/resources hrefs all resolve; tools, reports, JD templates, salary specialties, state directories all linked from registry-derived meshes; zero dead internal links (3 hrefs ride documented 301s). Strongest cross-check: scripted href-vs-route-tree scan + registry drift tests (`p5-comparison-pages-routes.test.ts`).
- **Content/components** — 27/28 setting-state FAQ builders (psych documented); 43/45 category FAQ surfaces; blog mdx ↔ content-map slots zero-diff both directions; SalaryProvenance on all five A4 surfaces; JobLocationContext and recruitment badges wired and test-pinned. Strongest cross-check: `p5-salary-provenance-surfaces.test.ts` + byte-identical CEU mdx pin.
